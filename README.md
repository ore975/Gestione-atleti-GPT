# Gestione Atleti - SS Lazio Theme

Web app Streamlit per gestione atleti, cartella clinica, valutazioni morfologiche, infortuni e farmacologia/antidoping.

## Avvio locale
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Pubblicazione online
Caricare questi file nel repository GitHub e collegare il repository a Streamlit Cloud.

> Nota: questa versione usa SQLite locale. Per uso clinico reale online e multiutente sarà necessario passare a PostgreSQL/Supabase con autenticazione e gestione GDPR.
